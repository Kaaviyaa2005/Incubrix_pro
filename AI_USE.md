# AI tool disclosure

- ChatGPT (OpenAI): used to assist with code changes, debugging suggestions, documentation, and reviewing the supplied assessment requirements. The candidate must review, test, understand and be able to explain every change before submission.
- `edge-tts`: used for script-to-speech generation.
- `faster-whisper`: used for automatic transcription of uploaded or recorded audio.
- No generated B-roll footage is produced by this prototype. All visuals are selected from the local media library.
